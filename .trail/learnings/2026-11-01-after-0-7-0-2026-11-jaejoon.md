## Decided
0.7.0 shipped to nuget.org on 2026-11-01 (contact points, HasCollision early exit, package
validation, TryCastRay/TryCastShape). The user agreed to wait 2-4 weeks (check around
2026-11-15, no later than 2026-11-29) for external feedback on the new cast API before 1.0.0.

Planned 1.0.0 scope:
- remove `OpenGjk.CsFunction` (the only breaking change; deprecated since 0.4.0)
- fix the EPA depth overestimate for nearly touching curved pairs (round 4 P2, present since 0.6.0,
  repro in docs/dogfooding/round4.md)
- bump `PackageValidationBaselineVersion` to 0.7.0
- one dogfooding round including a 0.7.0 -> 1.0.0 output diff (see dogfooding-rounds-outside-repo)

**Why:** 1.0 freezes the API; cast signatures are new and could still change if users report problems.

## Watch out
the first two items can land on main before the wait ends (no tag = no publish);
the decision gate is "any GitHub issue asking for a cast signature change?", not the calendar alone.
Work is done by subagents with the main session reviewing and approving each diff.
